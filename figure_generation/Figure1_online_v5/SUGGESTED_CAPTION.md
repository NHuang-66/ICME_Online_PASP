# Suggested Figure 1 caption

**Figure 1. Fixed-probability backbone and online ICME decision workflow.** **(a)** Chronologically preprocessed solar-wind measurements are passed through the fixed sequence model to obtain an ICME probability for each observation; model weights remain unchanged during deployment. **(b)** The online layer, implemented here with SAOCP, processes 64-observation blocks: it scores a block, selects a threshold from experts informed only by completed blocks, makes all decisions before current labels are revealed, and then updates the experts for the next block. The contribution of this work is the application of online decision updating to ICME detection under distribution drift, not the SAOCP algorithm itself. **(c)** Online binary decisions undergo gap-aware correction, are assembled into event intervals, and are evaluated against the catalog using maximum-cardinality one-to-one event matching. Matched pairs define true positives, whereas unmatched predicted and catalog events define false positives and false negatives, respectively, for event-level precision, recall, and F1. Miniature traces and sequences are explanatory glyphs rather than measured results.
